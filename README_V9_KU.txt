ALO SOLAR ENERGY V9 PRO APP

ئەم وەشانە Hybrid Native App ـە:
- هەمان داتای ڕاستەوخۆی alosolarenergy.com
- وێنەی ڕاستەقینەی product ـەکان لە وێبسایت
- هەمان Solar Calculator و logic ـی وێبسایت
- هەمان EVE Charge / Find My Charger
- Native bottom navigation
- Animated Alo splash
- AI Assistant ـی ناوخۆ بە کوردی/عەرەبی/ئینگلیزی

Android Studio:
1) Open ئەم folder ـە بکە.
2) flutter pub get
3) flutter run

تێبینی AI:
Assistant ـی ناوخۆ بۆ زانیاری و navigation کار دەکات. بۆ ChatGPT-style cloud AI ـی تەواو، پێویستە backend/API ـێکی پارێزراو پەیوەست بکرێت؛ API key نابێت ڕاستەوخۆ لە APK دابنرێت.
