ALO SOLAR ENERGY - V6 ANDROID READY

ئەم وەشانە بۆ Android Studio/Flutter ئامادە کراوە.

باشترین ڕێگا لە Windows:
1) ZIP ـەکە Extract بکە.
2) Flutter لە PATH دڵنیابە.
3) دوو کلیک لە REPAIR_AND_BUILD_WINDOWS.bat بکە.
4) فایلەکە خۆکار Android project ـەکە تەواو/چاک دەکات.
5) APK لێرە دروست دەبێت:
   build\app\outputs\flutter-apk\app-debug.apk

بۆ Android Studio:
- فۆڵدەری سەرەکی ALO_SOLAR_V6_ANDROID_READY بکەرەوە، نەک تەنها android.
- Flutter plugin و Dart plugin دەبێت دامەزرابن.
- JDK ـی Android Studio بەکاربهێنە.

گرنگ:
- پێویست ناکات android.newDsl=false زیاد بکەیت.
- فایلە بنەڕەتییەکانی MainActivity و styles زیاد کراون.
- لۆگۆی Alo Solar Energy لە ناو ئەپەکە زیاد کراوە.
